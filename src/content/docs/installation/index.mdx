If someone already runs Yorishiro for you, ask them for the server URL and an API key. You do not need to install it yourself. Continue with [Connect an MCP client](first-run/#4-connect-an-mcp-client).

## Choose an installation method

| Method                            | When to use it                                                        |
| --------------------------------- | --------------------------------------------------------------------- |
| [Docker Compose](docker-compose/) | Recommended for a first installation. Includes all required services. |
| [Packages (deb / rpm)](packages/) | Run on a Linux host managed with systemd.                             |
| [Docker](docker/)                 | Manage individual containers yourself.                                |
| [Build from source](build/)       | Build a version that is not available as a release.                   |

Start with SQLite for a personal installation. Choose PostgreSQL when you need several tenants or workers on different machines. See [SQLite mode](../guides/sqlite/).

After installation, [create the first account and connect your AI assistant](first-run/).

## What runs

Keep these four services running. The Compose examples include all four; the packages provide four systemd units.

| Service          | What you need it for                                       | Command                                         |
| ---------------- | ---------------------------------------------------------- | ----------------------------------------------- |
| Server           | API and MCP connections                                    | `yorishiro start`                               |
| Embedding worker | Search by meaning and updating search data                 | `yorishiro start --worker=worker-target:shared` |
| Application jobs | Imports, filling defaults, undo, and Enterprise inference  | `yorishiro start --worker=job-target:shared`    |
| Scheduler        | Recovering interrupted background work and scheduled tasks | `yorishiro scheduler`                           |

## Editions and versions

Community (`ce`) runs without a licence and supports one tenant. Enterprise (`ee`) adds features such as external identity-provider sign-in and per-workspace providers. See [Enterprise configuration](../configuration/enterprise/).

Choose a tag from [Releases](https://github.com/yorishiro-ai/yorishiro/releases) wherever a command shows `<VERSION>`. Use documentation that matches your chosen version: the current wiki follows product `develop`, and older releases may not have every command shown here.

Images are `ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce` and `ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ee`. There is no `latest` tag. Images and packages are available for `amd64` and `arm64`.
