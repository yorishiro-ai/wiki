Use a [package](../packages/) or [Docker Compose](../docker-compose/) unless you need a custom build. Source builds require Rust through [rustup](https://rustup.rs/), Python 3, a C/C++ toolchain, and the platform dependencies described in the [contributing guide](https://github.com/yorishiro-ai/yorishiro/blob/develop/CONTRIBUTING.md). Linux builds use `mold` and `sccache`.

## Build

```sh
git clone https://github.com/yorishiro-ai/yorishiro
cd yorishiro
git switch develop
python3 patches/loco-rs/verify.py --prepare
cargo build --locked --release --bin yorishiro --no-default-features --features community
```

The repository selects its Rust toolchain. Preparing the patched dependency is required on a fresh checkout. For Enterprise, omit `--no-default-features --features community`. The executable is `target/release/yorishiro`.

## Run

Run each command in a separate terminal, from the repository directory:

```sh
target/release/yorishiro start
target/release/yorishiro start --worker=worker-target:shared
target/release/yorishiro start --worker=job-target:shared
target/release/yorishiro scheduler
```

Source runs use `config/development.yaml` by default. To use production settings, set `LOCO_ENV=production` consistently for all four commands and configure writable data paths. See [Configuration](../../configuration/).

Continue with [First run](../first-run/) at `http://localhost:5150`. The embedding worker downloads its model on first start. Do not run all four commands sequentially in one terminal: the first keeps running.
