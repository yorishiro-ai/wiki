For a first installation, use [Docker Compose](../docker-compose/). Use this page if you want to manage each container yourself.

## Start the containers

Replace `<VERSION>` with the tag you chose from [Releases](https://github.com/yorishiro-ai/yorishiro/releases). Run the server first:

```sh
docker volume create yorishiro-data
docker volume create yorishiro-models

docker run -d --name yorishiro --restart unless-stopped -p 5150:5150 \
  -e BINDING=0.0.0.0 -e HOST=http://localhost:5150 \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce
```

Wait until `curl http://localhost:5150/_ping` succeeds, then start the other three containers:

```sh
docker run -d --name yorishiro-worker --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro -v yorishiro-models:/app/models \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce \
  start --worker=worker-target:shared

docker run -d --name yorishiro-jobs --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce \
  start --worker=job-target:shared

docker run -d --name yorishiro-scheduler --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce scheduler
```

The embedding worker downloads about 1 GiB on its first start. Keep all four containers running. Continue with [First run](../first-run/) at `http://localhost:5150`.

## Database and configuration

The example uses SQLite. All containers share the data volume; only the embedding worker needs the model volume. Do not delete the data volume when replacing containers.

For PostgreSQL, set the same `DATABASE_URL` on all four containers. For a Valkey queue, also set `YORISHIRO_QUEUE_KIND=Redis` and `QUEUE_URL` on all four. The [Compose guide](../docker-compose/#postgresql-and-valkey) includes a complete example with database extensions.

The image reads `/app/config/production.yaml`. Mount a complete configuration there if needed. A replacement file is not merged with the image's file. Set `HOST` to the URL your users connect to; `BINDING=0.0.0.0` lets the published port reach the server inside the container.

## Logs and stopping

```sh
docker logs --tail 100 yorishiro-worker
docker logs --tail 100 yorishiro-jobs
docker stop yorishiro yorishiro-worker yorishiro-jobs yorishiro-scheduler
```

For search failures or jobs that do not finish, see [Troubleshooting](../../operations/queue-start-objectives/).
