Choose a template that matches what you want to save. Ask your assistant to list the built-in templates with `list_templates`, then create a schema with `create_schema` and its `template_id`. Creating the schema needs `schema` access. See [Use Yorishiro with your AI assistant](../using-yorishiro/) for a first example.

| Template                  | For                                                                                                            | Entity types                                                                |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `general-notes`           | General notes with tags and links                                                                              | note                                                                        |
| `software-adr`            | Architecture decisions, a service catalog, and the tech stack of a software project                            | decision, service, incident                                                 |
| `task-management`         | Projects and tasks with deadlines, dependencies, clients, milestones, assignments, work sessions, and handoffs | project, task, client, milestone, assignee, work_session, handoff           |
| `research-knowledge-base` | Papers, authors, concepts, experiments, and datasets                                                           | paper, author, concept, experiment, dataset                                 |
| `game-dev-lore`           | Shared canon for a game: characters, locations, factions, items, events, glossary terms, and assets            | character, location, faction, item, event, term, asset                      |
| `creative-writing`        | Long-form writing: characters, places, organizations, items, chapters, scenes, plot threads, and events        | character, location, organization, item, chapter, scene, plot_thread, event |
| `trpg-campaign`           | Running a TRPG campaign: characters, locations, factions, items, sessions, quests, and encounters              | character, location, faction, item, session, quest, encounter               |
| `worldbuilding`           | Deprecated: characters, locations, factions, and items                                                         | character, location, faction, item                                          |

Each template also defines relation types between its entities.

For a template saved in your tenant's own library, use `list_template_library` to find its UUID and pass that as `template_id`. Inspect the schema before saving items so the assistant uses its actual field names and relation types.

## Deprecated template

`worldbuilding` is deprecated. For new work, use `creative-writing`, `trpg-campaign`, or `game-dev-lore`. The `template_id` value `worldbuilding` keeps working, and existing schemas stay unchanged.

## Schema versions and archival

`create_schema` creates a workspace-owned schema or its next immutable version; it does not rewrite historical versions. Inspect `get_active_schema`, `get_schema_by_id`, and `list_schemas` before changing a definition.

`archive_schema` requires `schema` scope and archives the specified version without deleting entities, historical definitions, bindings, or fork references. It does not reactivate an older version. Future creation under the same name advances the version sequence; archive is not physical deletion.

## Tenant template library

Tenant Admin/Owner can use `create_template_library_item`, `update_template_library_item`, `delete_template_library_item`, and `fork_template_library_item` to manage tenant-shared definitions under the tool's scope requirements. These are template-library resources, not physical PostgreSQL schemas. Workspace copies and their existing versions remain distinct when a library definition is edited or deleted.

Enterprise schema-fork management is separate from the tenant library and from Marketplace publishing. See [Enterprise configuration](../../configuration/enterprise/#template-updates-and-schema-forks).
