初めて導入する場合は[Docker Compose](../docker-compose/)を使ってください。このページはコンテナを個別に管理したい方向けです。

## コンテナを起動する

`<VERSION>`を[Releases](https://github.com/yorishiro-ai/yorishiro/releases)から選んだタグに置き換えます。まずサーバーを起動します。

```sh
docker volume create yorishiro-data
docker volume create yorishiro-models

docker run -d --name yorishiro --restart unless-stopped -p 5150:5150 \
  -e BINDING=0.0.0.0 -e HOST=http://localhost:5150 \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce
```

`curl http://localhost:5150/_ping`が成功してから、残りの3つを起動します。

```sh
docker run -d --name yorishiro-worker --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro -v yorishiro-models:/app/models \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce \
  start --worker=worker-target:shared

docker run -d --name yorishiro-jobs --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce \
  start --worker=job-target:shared

docker run -d --name yorishiro-scheduler --restart unless-stopped --no-healthcheck \
  -v yorishiro-data:/var/lib/yorishiro \
  ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce scheduler
```

埋め込みワーカーは初回に約1 GiBのモデルをダウンロードします。4つのコンテナを起動したまま、`http://localhost:5150`で[初回起動](../first-run/)に進んでください。

## データベースと設定

この例はSQLiteを使います。すべてのコンテナでデータ用ボリュームを共有し、モデル用ボリュームは埋め込みワーカーだけが使います。コンテナを置き換える際にデータ用ボリュームを削除しないでください。

PostgreSQLを使う場合は、4つすべてに同じ`DATABASE_URL`を設定します。Valkeyのキューも使う場合は、`YORISHIRO_QUEUE_KIND=Redis`と`QUEUE_URL`も4つすべてに設定します。データベース拡張を含む構成例は[Composeガイド](../docker-compose/#postgresqlとvalkey)を参照してください。

イメージは`/app/config/production.yaml`を読み込みます。必要なら完全な設定ファイルをこの場所にマウントします。イメージ内のファイルとはマージされません。`HOST`には利用者が接続するURLを指定します。`BINDING=0.0.0.0`は公開したポートからコンテナ内のサーバーに接続するための設定です。

## ログと停止

```sh
docker logs --tail 100 yorishiro-worker
docker logs --tail 100 yorishiro-jobs
docker stop yorishiro yorishiro-worker yorishiro-jobs yorishiro-scheduler
```

検索に失敗する場合や処理が終わらない場合は[トラブルシューティング](../../operations/queue-start-objectives/)を参照してください。
