このページはリリース済みの配布物ではなく自分で実行ファイルを用意したい方向けです。URLとAPIキーを受け取っている方は、ビルドせず[AIアシスタントを接続](../first-run/#4-mcpクライアントを接続する)してください。

独自のビルドが不要なら[パッケージ](../packages/)か[Docker Compose](../docker-compose/)を使ってください。ビルドには[rustup](https://rustup.rs/)で導入したRust、Python 3、C/C++ツールチェーンと、[開発ガイド](https://github.com/yorishiro-ai/yorishiro/blob/develop/CONTRIBUTING.md)にある環境ごとの依存関係が必要です。Linuxでは`mold`と`sccache`を使います。

## ビルドする

```sh
git clone https://github.com/yorishiro-ai/yorishiro
cd yorishiro
git switch develop
python3 patches/loco-rs/verify.py --prepare
cargo build --locked --release --bin yorishiro --no-default-features --features community
```

Rustのバージョンはリポジトリが指定します。新たにチェックアウトした場合は、修正済みの依存関係を準備する必要があります。Enterpriseでは`--no-default-features --features community`を省略します。実行ファイルは`target/release/yorishiro`です。

## 実行する

リポジトリのディレクトリで、それぞれ別のターミナルから実行します。

```sh
target/release/yorishiro start
target/release/yorishiro start --worker=worker-target:shared
target/release/yorishiro start --worker=job-target:shared
target/release/yorishiro scheduler
```

既定では`config/development.yaml`を使います。productionの設定を使う場合は、4つすべてで`LOCO_ENV=production`を設定し、書き込めるデータの保存先を指定してください。[設定](../../configuration/)を参照してください。

`http://localhost:5150`で[初回起動](../first-run/)に進みます。埋め込みワーカーは初回にモデルをダウンロードします。最初のコマンドは起動したままになるため、4つを1つのターミナルで順番に実行しないでください。
