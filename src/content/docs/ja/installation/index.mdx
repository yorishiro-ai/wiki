すでにYorishiroを運用している方がいる場合は、サーバーのURLとAPIキーを受け取ってください。自分でインストールする必要はありません。[MCPクライアントの接続](first-run/#4-mcpクライアントを接続する)へ進んでください。

## 導入方法を選ぶ

| 方法                                 | 用途                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| [Docker Compose](docker-compose/)    | 初めての導入におすすめです。必要なサービスがそろっています。 |
| [パッケージ（deb / rpm）](packages/) | systemdで管理するLinuxホストで動かします。                   |
| [Docker](docker/)                    | コンテナを個別に管理します。                                 |
| [ソースからビルド](build/)           | リリースにないバージョンをビルドします。                     |

個人で使う場合はSQLiteから始められます。複数のテナントや別のマシンで動くワーカーが必要ならPostgreSQLを選んでください。[SQLiteモード](../guides/sqlite/)を参照してください。

導入後は[最初のアカウントを作成し、AIアシスタントを接続](first-run/)します。

## 起動するサービス

次の4つを起動したままにしてください。Composeの例にはすべて含まれ、パッケージには4つのsystemdユニットが用意されています。

| サービス               | 用途                                                       | コマンド                                        |
| ---------------------- | ---------------------------------------------------------- | ----------------------------------------------- |
| サーバー               | APIとMCPの接続                                             | `yorishiro start`                               |
| 埋め込みワーカー       | 意味による検索と検索データの更新                           | `yorishiro start --worker=worker-target:shared` |
| アプリケーションジョブ | インポート、デフォルト値の補完、取り消し、Enterpriseの推論 | `yorishiro start --worker=job-target:shared`    |
| スケジューラー         | 中断したバックグラウンド処理の回復と定期処理               | `yorishiro scheduler`                           |

## エディションとバージョン

Community（`ce`）はライセンスなしで1つのテナントを利用できます。Enterprise（`ee`）では外部の認証サービスによるログインやワークスペースごとのプロバイダー設定などが加わります。[Enterprise設定](../configuration/enterprise/)を参照してください。

コマンドの`<VERSION>`には[Releases](https://github.com/yorishiro-ai/yorishiro/releases)から選んだタグを指定します。このwikiは製品の`develop`に追従しています。古いリリースには掲載中のコマンドがない場合があるため、利用するバージョンを確認してください。

イメージ名は`ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ce`と`ghcr.io/yorishiro-ai/yorishiro:<VERSION>-ee`です。`latest`タグはありません。イメージとパッケージは`amd64`と`arm64`向けに提供されています。
