自分のLinuxサーバーにYorishiroを導入するための手順です。管理者からURLとAPIキーを受け取っている場合は、インストールせず[AIアシスタントを接続](../first-run/#4-mcpクライアントを接続する)してください。

Ubuntu 24.04かAlmaLinux 10で使えます。glibc 2.39以降が必要です。`amd64`と`arm64`向けがあり、Community（`yorishiro-ce`）とEnterprise（`yorishiro-ee`）から選びます。同時にインストールできるのは片方だけです。

## インストールする

[Releases](https://github.com/yorishiro-ai/yorishiro/releases)から対象のパッケージと`checksums.txt`を取得します。`<VERSION>`をリリースタグに置き換えてください。`arm64`ではファイル名の`amd64`も変更します。

DebianやUbuntuでは次を実行します。

```sh
wget https://github.com/yorishiro-ai/yorishiro/releases/download/<VERSION>/yorishiro-ce-<VERSION>-amd64.deb
sudo apt install ./yorishiro-ce-<VERSION>-amd64.deb
```

AlmaLinuxでは次を実行します。

```sh
wget https://github.com/yorishiro-ai/yorishiro/releases/download/<VERSION>/yorishiro-ce-<VERSION>-amd64.rpm
sudo dnf install ./yorishiro-ce-<VERSION>-amd64.rpm
```

## 起動する

```sh
sudo systemctl enable --now yorishiro yorishiro-worker yorishiro-jobs yorishiro-scheduler
sudo systemctl status yorishiro yorishiro-worker yorishiro-jobs yorishiro-scheduler
```

`http://localhost:5150`で[初回起動](../first-run/)に進みます。埋め込みワーカーは初回に約1 GiBをダウンロードします。`sudo journalctl -u yorishiro-worker -f`で確認できます。

## インストール先

| パス                                     | 内容                                                    |
| ---------------------------------------- | ------------------------------------------------------- |
| `/usr/bin/yorishiro`                     | 実行ファイル                                            |
| `/etc/yorishiro/production.yaml.example` | パッケージとともに更新される設定例                      |
| `/etc/yorishiro/production.yaml`         | 自分で用意する完全な設定。省略可能                      |
| `/var/lib/yorishiro`                     | SQLiteのデータとキューのファイル、`models/`ディレクトリ |

Enterpriseには`/etc/yorishiro/LICENSE.enterprise`も含まれます。

## 設定

4つのサービスは同じ設定を使います。独自のファイルがなければ、パッケージの設定例を使い、SQLiteで動きます。`yorishiro.env`や`EnvironmentFile=`のオーバーライドは不要です。

設定を変更する場合は、既存の設定がないときだけ例をコピーします。

```sh
sudo cp -n /etc/yorishiro/production.yaml.example /etc/yorishiro/production.yaml
sudo chown root:yorishiro /etc/yorishiro/production.yaml
sudo chmod 640 /etc/yorishiro/production.yaml
sudoedit /etc/yorishiro/production.yaml
```

サービスの`yorishiro`ユーザーが読めるようにしてください。この権限なら、ほかのユーザーはパスワードを読めません。既存の設定は編集前にバックアップします。独自のファイルはパッケージの設定を置き換えるため、アップグレード後は新しい例と比較してください。

PostgreSQLでは`database.uri`に接続URIを指定します。キューの条件分岐全体は1つの`queue:`ブロックに置き換えます。選んだプロバイダーの項目を残し、`kind: Postgres`と`uri`を指定して、ほかの分岐とテンプレートの条件行を削除してください。Valkeyでは代わりに`kind: Redis`と`redis://`または`rediss://`のURIを使います。`database.uri`だけを編集しても、例のキュー選択は変わりません。

別のマシンから接続する場合は、`server.binding`を`localhost`から`0.0.0.0`に変更し、`server.host`に利用者が接続するURLを指定します。[設定](../../configuration/)を参照してください。

編集後に再起動します。

```sh
sudo systemctl restart yorishiro yorishiro-worker yorishiro-jobs yorishiro-scheduler
```

サービスが書き込めるのは`/var/lib/yorishiro`だけです。書き込みが必要なSQLiteやモデルのファイルはここに置いてください。起動に繰り返し失敗する場合は[トラブルシューティング](../../operations/queue-start-objectives/)を参照してください。
